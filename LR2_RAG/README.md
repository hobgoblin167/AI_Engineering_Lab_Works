# Лр2 (RAG)

**Тема:** Построение систем RAG (Retrieval-Augmented Generation) на базе корпуса литературных произведений.

### **1. Описание материалов и ресурсов**

Для выполнения работы предоставлены следующие компоненты:

- LR2.csv — основной набор данных (100 вопросов);
- LR2_dev.csv — пробный набор данных для отладки (50 вопросов);
- LR2_dev_answer.csv — эталонные ответы к пробному набору;
- **Библиотека текстов** — корпус литературных произведений в электронном формате, служащий базой знаний для системы RAG.

### **2. Структура данных и формат ответов**

Файлы с заданиями содержат 7 столбцов:

1. Идентификатор вопроса.
2. Текст вопроса.
3. Вариант ответа A.
4. Вариант ответа B.
5. Вариант ответа C.
6. Вариант ответа D.
7. Название литературного произведения.

⚠️ **Важное отличие:** В данной лабораторной работе нумерация ответов начинается **с 1** (индексы: 1, 2, 3 или 4).

### **3. Допустимый стек технологий (LLM)**

Для обеспечения равных условий и технической воспроизводимости разрешено использование только следующих локальных моделей:

- **Gemma-3** (версии до 4b параметров включительно);
- **Gemma-3n-E2B-it**;
- **Qwen-3** (версии до 8b параметров включительно);
- **Qwen-2.5** (версии до 8b параметров включительно).

**Технические условия:**

- Модели должны запускаться исключительно на локальных мощностях.
- Использование внешних API-интерфейсов категорически **запрещено**.
- Любая попытка обхода данных ограничений ведет к немедленному обнулению работы.

### **4. Порядок оценивания**

Оценка выставляется исходя из процента правильных ответов.

- Шкала проходных баллов будет опубликована дополнительно (TBA).
- При выявлении фактов плагиата выставляется **0 баллов** всем вовлеченным сторонам без права пересдачи.

Итоговый балл рассчитывается на основе процента корректных ответов:

| Процент ответов | Балл | Процент ответов | Балл |
| --- | --- | --- | --- |
| < 40% / Плагиат | 0 | 60% + | 6 |
| 40% + | 1 | 65% + | 7 |
| 43% + | 2 | 70% + | 8 |
| 45% + | 3 | 73% + | 9 |
| 50% + | 4 | 76% + | 10 |
| 55% + | 5 |  |  |

### **5. Процедура подачи работы**

Загрузка материалов осуществляется через **специализированную форму**.

**Необходимый комплект файлов:**

1. **Файл с ответами (.csv):** должен соответствовать структуре файла LR2_dev_answer.csv.
2. **Программный код (.py):** один файл (например, main.py), содержащий логику работы системы.

**Правила подачи:**

- Количество попыток загрузки не ограничено. К зачету принимается результат с наивысшим баллом.
- Промежуточные результаты будут отображаться в **сводной таблице**.

### **6. Академическая этика и требования к коду**

- **Проверка на плагиат:** Будет проведена в автоматическом и ручном режимах после истечения дедлайна.
- **Воспроизводимость:** Работа должна быть полностью воспроизводима. Если преподаватель не сможет получить заявленный результат, используя предоставленный код, он имеет право аннулировать баллы или выставить оценку на основе фактически полученного при проверке результата.
